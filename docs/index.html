pygwin

A Windows-first, Python-powered shell and system observability console. A fork of xonsh.

What it is

pygwin runs real Python, mixed freely with subprocess commands, in one interactive shell. It is built on xonsh's parser and shell engine, renamed throughout, with a leaner default configuration and a different goal: a shell that also watches your machine while you use it, with live CPU and memory telemetry and transparent process auto-tuning built in.

Install

git clone https://github.com/dayanez/pygwin.git
cd pygwin
pip install -e ".[full]"
pygwin

Or download the standalone pygwin.exe from the Releases page. No Python install required.

Status

Every item this project set out to do for its first real release has now landed: the rebrand from xonsh, a working CI and CD pipeline, a compiled standalone pygwin.exe, and its two differentiators, the sysinfo and autotune pgtribs, live telemetry and transparent process priority tuning. See the README's Status section for the full detail.
